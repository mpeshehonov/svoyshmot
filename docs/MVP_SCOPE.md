# MVP Scope — СвойШмот

Стадия: **MVP** · Stage gate: ранние сигналы product-market fit

## Validated Problem (гипотеза)

Люди хотят уникальную одежду по своей идее, но не умеют шить и не знают, как найти ателье с прозрачными условиями.

**Нужно подтвердить:** 5–10 интервью с потенциальными клиентами и 3–5 с ателье в одном городе (wedge).

## Target User (wedge)

1. **Клиент:** 25–40, город 500k+, хочет «свой» предмет (платье, куртка), готов ждать 2–4 недели.
2. **Ателье:** малые мастерские, ищут заказы без агрегаторов с высокой комиссией.

## Core Interaction

Промпт → дизайн → заказ с параметрами → публикация → ставки ателье → выбор → чат → статусы пошива.

## Included In MVP (сделано / в работе)

| Область | Статус |
|--------|--------|
| Auth (клиент / ателье), RU-ошибки | ✅ |
| Кабинет клиента, сохранение промпта | ✅ |
| Заказ: черновик → публикация → ставки → принятие | ✅ |
| Кабинет ателье, ставки, статусы, чат | ✅ |
| AI-генерация 4 вариантов изображения | ❌ Stage 2 |
| Оплата / эскроу | ❌ После PMF |
| Рейтинги, отзывы, модерация | ❌ |
| Мобильное приложение | ❌ |

## Deliberately Excluded

- Платежи, доставка, возвраты
- Публичная лента с реальными AI-картинками
- Мультигород / логистика между городами
- Админ-панель, антифрод
- SEO-лендинг под все категории одежды

## Feature Amendment Criteria

Фича входит в scope только если:
- без неё целевой пользователь **не может** завершить core interaction;
- сигнал повторяется у **≥3** пользователей одного сегмента;
- улучшает доверие (оплата, статус, прозрачность) или конверсию в заказ.

## Measurement Plan

| Метрика | Цель MVP | Как мерить |
|---------|----------|------------|
| Activation | регистрация → первый сохранённый дизайн | Supabase events / простой лог |
| Order intent | дизайн → опубликованный заказ | `orders.status = published` |
| Supply | ≥1 ставка на заказ | `order_bids` |
| Match | заказ → `accepted` | `orders.status` |
| Day 7 return | повторный визит | analytics |
| False PMF | регистрации без заказа, «друзья ради любопытства» | отдельно считать organic vs invited |

**North Star (MVP):** доля опубликованных заказов, получивших ≥1 ставку в 7 дней.
