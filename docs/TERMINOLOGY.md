# Терминология — СвойШмот

## В UI

| Термин | Значение |
|--------|----------|
| **Продавец** | Любая сторона, которая шьёт/производит одежду под заказ |
| **Тип продавца** | Ателье · Мастерская · Бренд · Другое производство |

Клиент не выбирает «ателье» — он выбирает **продавца** по цене, сроку и рейтингу. В карточке предложения видно название и тип (мастерская, бренд и т.д.).

## В коде и БД (пока без рефакторинга)

| Техническое | Смысл |
|-------------|--------|
| `role: atelier` | Пользователь-продавец |
| таблица `ateliers` | Профиль продавца |
| `/seller/*` | Маршруты кабинета продавца |
| `seller_kind` | Подтип: `atelier` \| `workshop` \| `brand` \| `other` |

Все пользовательские строки — в `packages/shared/src/seller.ts` (`SELLER_COPY`, `SELLER_KINDS`).

## Когда менять

- Новый текст на сайте → добавить в `SELLER_COPY`, не хардкодить «ателье».
